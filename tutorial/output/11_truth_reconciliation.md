# HTE 评价指标的真值对账（n_test = 2000，连续结局 RCT）

| 层 | 真值 | IPW 估计 | 估计 − 真值 |
|---|---|---|---|
| 随机排序 | 0.0076 | 0.1140 | 0.1065 |
| 模型排序 | 0.2618 | 0.3121 | 0.0503 |
| oracle 排序 | 0.2887 | 0.3477 | 0.0591 |

## 分解

- oracle 真值（排序天花板）：0.2887
- 排序损失（模型没排对）：0.0269，占天花板 9.3%
- 估计噪声（IPW 抽样误差）：0.0591，占天花板 20.5%
- 排序效率 = 模型真值 / oracle 真值：0.9067
- 噪声标尺（随机排序真值恒为 0，实测 0.0076）：0.1065
- 排序差异 0.0269 远小于噪声标尺 0.1065 → **单次 IPW 估计分辨不出排序优劣**

## c-for-benefit：没有真值，只有上界

- 信噪比 rho = sd(tau)/sd(观测获益) = 0.5107
- 理论天花板 0.5 + asin(rho)/pi = 0.6706
- oracle 实测 0.6638 / 模型实测 0.6457 / 随机 0.5062

## 观察性数据（n = 4000，真 ATE = 1.046）

- 模型真值 0.2523 / oracle 真值 0.2850
- 传 propensity 的估计 0.2666（残差 0.0143 = 噪声）
- 不传 propensity 的估计 1.0535（偏差 0.8012 = 混杂）
- 噪声标尺 0.0383，偏差是它的 21 倍 → propensity 修的是**系统偏差**，不是噪声
