### 对账指标约定：不能只报 ATE

模拟数据自带真值，所以每个场景都该同时报下面几组指标。**只报 ATE 是不够的**——ATE
是一个数，只说明人群平均效应估得准不准；CATE 的全部意义在于异质性，只有相关和误差
才回答「模型有没有把谁更获益排出来」。

| 指标 | 算法 | 回答什么 |
|---|---|---|
| **ATE 偏差** | 估计 ATE − 真实 ATE | 平均层面偏没偏；观察性数据上这是混杂的照妖镜 |
| **CATE 相关** | `cor(估计 CATE, 真实 tau)`（Pearson） | 有没有抓住异质性的方向与排序；接近 1 才说明真的在区分病人 |
| **RMSE** | `sqrt(mean((估计 CATE - tau)^2))` | 逐人估计误差的绝对尺度，可跨结局类型横向比较 |
| **估计 SD vs 真实 SD** | `sd(估计 CATE)` 与 `sd(tau)` 对比 | 有没有被「压平」——S-learner 常把异质性抹掉，SD 明显小于真值就是信号 |
| **分位数对照** | 估计 / 真实的 0/25/50/75/100% 分位 | 分布形状是否一致，比单一相关系数更直观 |

**一句话读法**：ATE 偏差小 + 相关低 = 平均对、异质性没学到（基学习器太弱或正则化
过头）；相关高 + RMSE 大 = 排序对、绝对尺度偏（R/DR 的二阶段对伪结果回归没有尺度
约束，容易出现）；两个都好，这个 learner 才敢说在这份数据上真的可用。

脚本 01–07 的对账表全部按这套口径出数；只关心排序时把 Pearson 换成 Spearman 即可。
场景 2 与场景 6 是「ATE 对但 CATE 错」的两个现成反例，值得单独看。


## 0. 数据生成机制与 DAG（脚本 00）

六个场景共用一套协变量与两种处理分配机制，**结局方程则随结局类型各有一套**。
脚本 `00_数据生成机制与DAG.R` 逐步展开每一步，并打印全部真值。
本节所有公式逐行照抄包内 `R/api.R` 的生成逻辑。

**共同骨架：协变量**

```
age ~ N(60, 12)    lac ~ N(2.5, 1.2)    tumor ~ N(5, 2)    sex ~ Bern(0.45)
z1 = scale(lac)    z2 = scale(tumor)      # z1 乳酸（越高病情越重），z2 瘤负荷
```

**两种分配机制 → 两张 DAG**：

| 设计 | 分配 | 因果结构 |
|---|---|---|
| RCT | `A ~ Bernoulli(0.5)` | `A` 无父节点，`A ⊥ X`，无混杂 |
| 观察性 | `e = plogis(−0.5 + 0.8·z1 + 0.4·z2)`，`A ~ Bernoulli(e)` | `X → e → A`，后门路径 `A ← e ← X → 结局 → Y` 开放 |

**三种结局，三套方程**：

| 结局 | 生成方程（源码原文） | 效应尺度 |
|---|---|---|
| 连续 | `tau = 1.0 + 0.8·z1 − 0.5·z2 + 0.6·(z1>1 & z2<0)`<br>`mu = 6 + 0.4·z1 + 0.5·z2 − 0.02·(age−60) + 0.3·sex`<br>`Y = mu + A·tau + N(0,1)` | 均值差 `tau` |
| 二分类 | `p0 = plogis(−1.2 + 0.5·z1 + 0.4·z2 + 0.1·(age−60)/12 + 0.2·sex)`<br>`tau_logit = 0.6 + 0.5·z1 − 0.4·z2`（对数几率尺度）<br>`p1 = plogis(qlogis(p0) + tau_logit)`；`Y ~ Bern(p_A)` | 风险差 `p1 − p0` |
| 生存 | `tau = 0.5 + 0.4·z1 − 0.3·z2`（对数风险尺度）<br>`base_rate = exp(−1.0 + 0.3·z1 + 0.2·z2 + 0.1·(age−60)/12 + 0.15·sex)`<br>`rate = base_rate·exp(−A·tau)`；`T ~ Exp(rate)`；删失 `C ~ Exp(0.12)` | `S(t₀)` 差（默认 t₀=2），另报 RMST 差 |

**六个数据集的真实值**（脚本 00 的实际输出）：

| 数据集 | 结局类型 | 真实 ATE | CATE 标准差 | CATE 范围 | ATE_RMST |
|---|---|---|---|---|---|
| 连续 × RCT | 连续 | 1.05 | 1.04 | −2.58 ~ 4.85 | — |
| 二分类 × RCT | 风险差 | 0.131 | 0.133 | −0.232 ~ 0.563 | — |
| 生存 × RCT | S(t₀) 差 | 0.152 | 0.151 | −0.460 ~ 0.590 | 0.192 |
| 连续 × 观察性 | 连续 | 1.05 | 1.04 | −2.14 ~ 5.03 | — |
| 二分类 × 观察性 | 风险差 | 0.131 | 0.132 | −0.243 ~ 0.616 | — |
| 生存 × 观察性 | S(t₀) 差 | 0.152 | 0.150 | −0.371 ~ 0.664 | 0.192 |

两个要点：**①** CATE 均值恒等于 ATE，但标准差超过 1.0——平均数掩盖了个体差异，
这是异质性方法的用武之地；**②** 观察性与 RCT 的真实 ATE 完全相同，
差别只在分配机制——观察性数据的粗差分偏出 +0.69 纯粹是混杂造成的。

文档站上有配色版 DAG：<https://zhangkaicr.github.io/mlr3HTE/#/tutorial/dgp>

## 1. 统一架构：一句话讲清楚

五种 Meta-Learner 的公式**与结局类型无关**。它们只跟一个东西打交道：

> **结局模型** —— 一个能返回 `predict(newX)` 的对象。

| 结局类型 | 结局模型返回 | CATE 的含义 |
|---|---|---|
| 连续 | `E[Y \| X]` | 均值差 `E[Y(1)-Y(0)\|X]` |
| 二分类 | `P(Y=1 \| X)` | **风险差** `P(Y(1)=1\|X) - P(Y(0)=1\|X)` |
| 生存 | `S(t0 \| X)` | **t0 时点生存概率差** `S₁(t0\|X) - S₀(t0\|X)` |

于是：

```
S-Learner  = 把 A 当普通特征塞进结局模型，两个反事实预测相减
T-Learner  = 两组各拟合一个结局模型，预测相减
X-Learner  = 插补个体治疗效应，再按倾向得分 g(X) 加权融合
R-Learner  = Robinson 残差化：(Y - m(X)) / (A - e(X))，以 (A-e)² 加权回归
DR-Learner = 双重稳健伪结果 psi，回归一次
```

**同一个骨架，换掉结局模型就换了结局类型。** 这就是本包 780 行代码能同时覆盖
3 类结局 × 2 种数据 × 5 种 learner（共 30 种组合）的原因。

## 2. 六格矩阵：三类结局 × 两种数据

| | **随机化试验（RCT）** | **观察性研究** |
|---|---|---|
| **连续** | `learner_base = lrn("regr.ranger")` <br> 效应 = 均值差 | 混杂因子放进 `X` 条件化 <br> 效应 = 均值差 |
| **二分类** | `learner_base = lrn("classif.ranger")` <br> 效应 = 风险差 | 同上，混杂因子放进 `X` <br> 效应 = 风险差 |
| **生存** | `learner_base = "coxph"` <br> 效应 = t0 生存概率差 | 同上，再加引擎自动的删矢 IPCW |

**RCT 与观察性的唯一区别**是「混杂因子有没有进 `X`」：

- **RCT**：`A ⊥ X`，倾向得分退化成常数，R/X/DR 里的 `e(X)` 直接用常数（也可以
  显式传 `learner_ps = 0.5`）。
- **观察性**：处理分配依赖协变量，后门路径 `A ← e ← X → 结局 → Y` 开放。
  把全部混杂因子放进 `X`，让结局模型条件化——S/T/X 靠 `E[Y|A,X]`，
  R 靠残差化，DR 两者都做。

> ⚠️ 这是**设计层面**的区别，不是代码技巧能补救的：观察性数据里如果
> `A` 与 `X` 存在未测量的混杂，任何方法都救不回来。
> 教程里所有观察性示例的混杂都是**已测量**的，所以条件化有效。
>
> **v0.40 起没有 `weighting` 参数。** 经典 metalearner 文献（Künzel et al. 2019
> PNAS）与 CausalML 的 BaseS/BaseT/BaseX 都不给结局模型套 IPTW；本包早期提供的
> `weighting = "iptw"` / `"external"` / `stabilize` 本质是「加权结局回归」，
> 属单稳健，已整体移除。

生存结局额外多一层：**删矢**。包内的分工是——

- **S / T 学习器**：结局模型本身就是生存模型（Cox 偏似然），删矢已在似然里正确处理，
  不需要额外权重。
- **X / R / DR 学习器**：需要个体尺度的结局，取 `I(T > t0)`，此时会乘上
  **删矢 IPCW 权重** `1 / G(Tᵢ⁻)`（用一个 Cox 模型对删矢指示建模得到）。

## 3. 五种 Meta-Learner：公式与选用

记 `m(x) = E[Y|X]`、`e(x) = P(A=1|X)`、`m₁(x) = E[Y|X,A=1]`、`m₀(x) = E[Y|X,A=0]`。

| Learner | 核心公式 | 优点 | 什么时候别用 |
|---|---|---|---|
| **S** | `m̂(x, A=1) - m̂(x, A=0)`，单模型 | 最省数据，只用一次全部样本 | 基学习器不建模交互时 CATE 会退化成常数（Cox 尤其明显） |
| **T** | `m̂₁(x) - m̂₀(x)`，两组各一个 | 简单稳健，直观 | 两组样本量相差悬殊或某组很小时 |
| **X** | 插补 `D₁ = Y - m̂₀(x)`（治疗组）、`D₀ = m̂₁(x) - Y`（对照组）→ 分别回归出 `τ̂₁, τ̂₀` → `g(x)·τ̂₀ + (1-g(x))·τ̂₁` | 组间不均衡时表现最好 | 两组都够大时收益不明显 |
| **R** | `τ̂ = argmin Σ wᵢ·[(Ỹᵢ - τ(xᵢ))²]`，其中 `Ỹ = (Y - m̂)/(A - ê)`、`w = (A - ê)²` | 理论性质好，对 `m` 的估计误差不敏感 | 伪结果噪声大，需要**正则化**的二阶段学习器 |
| **DR** | `ψ = m̂₁ - m̂₀ + A(Y-m̂₁)/ê - (1-A)(Y-m̂₀)/(1-ê)`，回归 `ψ ~ X` | 双重稳健：`m` 或 `e` 任一正确即一致 | 同上，二阶段要正则化 |

**默认选用建议**

- 想省事、两组都大 → **T**
- 两组不均衡（观察性常见）→ **X**
- 想有双重稳健保障 → **DR**
- R 需要仔细调二阶段学习器，否则容易翻车

## 5. 分格教程

### 5.1 连续结局 × RCT（脚本 01）

```r
d <- mlr3HTE_demo_data(n = 4000, seed = 1201)
lb <- lrn("regr.ranger", num.trees = 300, seed = 1)
fit <- metalearner("T", d$X, d$A, d$Y, learner_base = lb)
```

真值对账（`d$tau` / `d$ate` 已知）：

| Learner | ATE | 与真相关 | RMSE |
|---|---|---|---|
| S | 0.935 | 0.895 | 0.48 |
| T | 0.951 | 0.845 | 0.65 |
| X | 0.950 | 0.963 | 0.30 |
| R | 0.450 | 0.812 | 0.91 |
| DR | 0.954 | 0.924 | 0.43 |

真实 ATE = 1.048。**R 的 ATE 明显偏低**——这是 R-Learner 在默认设置下的已知弱点，
不是 bug（见第 8 节）。

---

### 5.2 连续结局 × 观察性（脚本 02）

```r
d <- mlr3HTE_demo_obs(n = 4000, seed = 1204)   # 含混杂：病情越重越容易接受处理
naive <- mean(d$Y[d$A == 1]) - mean(d$Y[d$A == 0])          # 有偏
fit   <- metalearner("X", d$X, d$A, d$Y,
                     learner_base = lrn("regr.ranger", num.trees = 300, seed = 1))
```

把全部混杂变量放进 `X` 后，五族的对账（真实 ATE = 1.049，真实 CATE SD = 1.039）：

| Learner | 估计 | 偏差 | 与真相关 | RMSE | 估计 SD |
|---|---|---|---|---|---|
| 未调整差分 | 1.738 | **+0.689** | — | — | — |
| S | 1.060 | +0.011 | 0.875 | 0.507 | 0.972 |
| T | 1.029 | −0.020 | 0.821 | 0.666 | 1.153 |
| **X** | **1.005** | **−0.044** | **0.954** | **0.320** | 0.937 |
| R | 0.976 | −0.073 | 0.736 | 0.853 | 1.241 |
| DR | 0.996 | −0.053 | 0.858 | 0.586 | 1.126 |

**反面对照：漏掉一个混杂因子。** 把 `lac` 从 `X` 里拿掉，五族一起偏回
+0.65 ~ +0.67，与未调整的 +0.689 几乎重合。变量没选对时，换 learner、
换更高级的方法都救不回来——这是设计层面的问题。

**R/DR 必须开交叉拟合。** R-learner 的 tau 回归以残差 `Y − mu` 为伪结局；
mu 若在同一批数据上估，ranger（默认 `min.node.size = 5`）会过拟合把残差压向 0：

| 情形 | 估计 | 偏差 |
|---|---|---|
| R，不开交叉拟合 | 0.432 | **−0.617** |
| R，开交叉拟合 | 0.976 | −0.073 |

### 5.5 生存结局 × RCT（脚本 05）

```r
d <- mlr3HTE_demo_surv(n = 4000, t0 = 2, seed = 1203)
```

| 要点 | 说明 |
|---|---|
| `learner_base` | `"coxph"`（默认，线性）或 `"ranger"`（非线性）。两者都是**原生实现，不依赖 mlr3proba**；传 `lrn("surv.*")` 会被拒绝 |

### 5.7 生存引擎二选一（脚本 09）

生存结局有两套引擎，`engine` 参数切换（默认 `"native"`，行为零变化）：

## 8. 调参与避坑

### 8.1 二阶段学习器要正则化（最容易踩的坑）

X/R/DR 的第二阶段是对**伪结果**做回归，噪声结构和结局模型完全不同
（R 的目标含 `1/(A-e)` 放大）。ranger 回归默认 `min.node.size = 5`，树太深会把
伪结果里的噪声也拟合进去：

| 设置 | 连续 R 相关 | 二分类 X 相关 | 生存 X 相关 |
|---|---|---|---|
| `min.node.size = 5`（ranger 默认） | 0.668 | 0.599 | 0.652 |
| `min.node.size = 50`（引擎默认） | **0.904** | **0.779** | **0.872** |

引擎在 `learner_tau = NULL` 时**不沿用** `learner_base`，而是单独建一个
`regr.ranger(num.trees = 500, min.node.size = 50)`。要覆盖：

```r
metalearner("R", X, A, Y, learner_tau = lrn("regr.ranger", min.node.size = 20))
metalearner("R", X, A, Y, learner_tau = lrn("regr.lm"))   # 生存 R/DR 常常更好
```

### 8.2 复现要设种子

引擎内部多处用到随机过程：ranger 的树生长、R/DR 的交叉拟合折序。
需要复现结果时：

```r
set.seed(2026)
metalearner("X", X, A, Y, learner_base = lrn("regr.ranger"))
```

### 8.3 R/DR 一定要开交叉拟合

R-learner 的 tau 回归以残差 `Y − mu` 为伪结局。mu 若在同一批数据上估，
高弹性学习器（ranger 默认 `min.node.size = 5`）会过拟合把残差压向 0，
tau 整体被砍掉一截——实测连续结局下 R 的 ATE 从 0.976 掉到 0.432（真实 1.049）。

```r
metalearner("R", X, A, Y, cross_fitting = TRUE)   # 默认建议
metalearner("R", X, A, Y, cross_fitting = FALSE)  # 会给出 cli 警告
```

### 8.4 生存 R/DR 的 CATE 可能越出 [-1, 1]

二阶段回归不受概率尺度约束，个别点会越界。这是**方法固有属性**，不是 bug。
S/T 的 CATE 是两个生存概率之差，严格有界。

### 8.5 基学习器类型必须与结局匹配

| 结局 | 允许 | 报错提示 |
|---|---|---|
| 连续 | `lrn("regr.*")` | 传 `classif.*` 会报「不匹配」 |
| 二分类 | `lrn("classif.*")` | — |
| 生存 | `"coxph"` / `"ranger"`（原生实现） | 传 `lrn("surv.*")` 会报错（需 mlr3proba） |

| 强度 | 未调整 | S | T | X | R | DR |

| 1.0 | +0.709 | +0.061 | +0.067 | +0.043 | +0.020 | −0.011 |
| 1.5 | +0.919 | +0.100 | +0.099 | +0.052 | +0.062 | −0.057 |
| 2.0 | +1.048 | +0.137 | +0.134 | +0.060 | +0.040 | −0.045 |

**留出集 CATE 相关**：

| 强度 | S | T | X | R | DR |
|---|---|---|---|---|---|
| 0（RCT） | 0.910 | 0.893 | 0.955 | 0.867 | 0.912 |
| 0.5 | 0.909 | 0.895 | 0.954 | 0.850 | 0.909 |
| 1.0 | 0.899 | 0.891 | 0.942 | 0.797 | 0.871 |

- **条件化确实能去混杂**：混杂全进 X 时五族 |偏差| 始终 ≤ 0.137，

## 12. RCT 基准测试：没有真实 tau 时怎么比模型（脚本 14）

### 12.1 先说清楚前提

脚本 01–11 里的对账（CATE 相关 / RMSE）建立在**知道每个人真实效应**之上，
这只有自带真值的模拟数据给得出。**现实 RCT 数据永远拿不到 tau**，
所以「跑一遍 mlr3 `benchmark()`、看 CATE 相关」这套做法只适用于模拟研究。

现实研究换一个问题问：**模型把「谁更获益」排到前面的能力如何**。
这不需要 tau，只需要随机化保证的可交换性：

| 指标 | 随机基线 | 回答什么 |
|---|---|---|
| Qini 系数（归一化） | ≈ 0 | 按模型排序靶向，比随机分配多出多少额外增益 |
| TOC 增益 | 0 | TOC 曲线与全样本 ATE 水平线夹的面积；量纲 = 结局单位 |
| c-for-benefit | 0.5 | 增益匹配后的 C 统计量，0.5 = 排序等于随机 |

随机基线不是精确的 0：归一化 Qini 除了随机线下的面积，而那个面积本身小，
单次随机排序能在 ±0.25 摆。本包演示数据（n = 1500）实测 10 次随机排序，
归一化 Qini 落在 −0.253 到 0.227。**比模型要看相对次序，别拿绝对阈值当基线。**

### 12.2 为什么必须交叉拟合

在自己训练过的数据上算这些指标，模型会把训练噪声也排进序里。
`hte_benchmark()` 的做法是每个 learner 在 K 折训练折上拟合、留出折上预测，
最后用全部留出预测（out-of-fold）拼一条 CATE。实测对照（X-learner，n = 1500）：

| 做法 | qini_normalized | c_for_benefit |
|---|---|---|
| in-fold（回代训练数据） | 0.528 | **0.663** |
| out-of-fold（5 折交叉拟合） | 0.404 | 0.617 |
| 真实 tau（参考上界） | 0.522 | 0.624 |

in-fold 的 c-for-benefit **超过了真实 tau**——那不是模型好，是把噪声也排序了。

### 12.3 代码

```r
bm <- hte_benchmark(d$X, d$A, d$Y, tau = d$tau, seed = 42)
bm$table

# 现实 RCT 数据：没有 tau，输出里就不会有 tau_cor / tau_rmse 两列
bm <- hte_benchmark(X, A, Y, seed = 42)

plot_hte_benchmark(bm, "qini")
plot_hte_benchmark(bm, "toc")
```

值得注意的几点：

- `learner_base` 所有 learner 共用一个，比出来的差异才归因于 meta-learner
  而不是基学习器；默认按结局类型自动选（连续 ranger / 二分类 classif.ranger / 生存 coxph）。
- `n_folds` 的折**按处理组分层**，保证每折两个臂都有样本——不分层时某一折
  可能全是同一个臂，该折的效应估计直接失效。
- `tau` 是可选的。给了就多两列 `tau_cor` / `tau_rmse`，
  于是 Qini 三件套和「有真值」的两套指标能对着看。
- 观察性数据把 `propensity` / `mu1` / `mu0`
  （`dr_pseudo_outcome()` 的输出）一起传进来即可，指标算法不变。

### 12.4 实测结果与一条重要提醒

连续 × RCT（n = 1500，5 折交叉拟合，seed = 42，真实 ATE 1.049）：

| learner | ate | qini_normalized | toc_gain | c_for_benefit | tau_cor |
|---|---|---|---|---|---|
| S | 1.040 | 0.417 | 0.516 | 0.613 | 0.908 |
| T | 1.100 | 0.378 | 0.492 | 0.608 | 0.894 |
| X | 1.090 | 0.404 | 0.647 | 0.617 | 0.946 |
| R | 0.498 | 0.460 | 0.946 | 0.599 | 0.857 |
| DR | 1.090 | 0.413 | 0.568 | 0.617 | 0.932 |

R 的 ATE 只有 0.498（真值 1.049），可 qini_normalized 和 toc_gain 都是五个里最高的。
原因：R-learner 二阶段对伪结果回归，**没有尺度约束**，CATE 可以整体缩小一半而排序不变。
Qini / TOC 只看排序，对尺度错误视而不见。

> **ATE 和 Qini 必须一起报**：前者回答「平均对不对」，后者回答「排序好不好」。
> 只看任何一列都会得出错误结论。

## 10. 模型评价：真值标尺（脚本 10 / 11）

前面九节回答「ATE 估得准不准」。这一节回答另一个问题：**模型把「谁获益更多」
排前面的能力如何**，以及——模拟数据里真值已知时，这些指标**本该是多少**。

### 10.1 三个指标与观察性数据的两条修正路径

| 指标 | 函数 | 观察性数据要补什么 |
|---|---|---|
| Qini 曲线 / 系数 | `qini_curve()` / `qini_coefficient()` | `propensity = e(X)` |
| TOC 曲线 | `toc_curve()` | `propensity = e(X)` |
| c-for-benefit | `c_for_benefit()` | `propensity` + `mu1` + `mu0`（三件套缺一不可） |

三件套用 `dr_pseudo_outcome(X, A, Y, seed = )` 一次拿到，默认 5 折交叉拟合。
**只给 `c_for_benefit()` 一个倾向得分会报错**：那等价于拿 Horvitz–Thompson 评分
当观测获益，本包演示数据上该评分单次样本 SD ≈ 15（ATE ≈ 1），即使用真 `tau`
排序 C 统计量也只有 0.39，比随机还差。

### 10.2 用真值当标尺：把误差拆成两块

`tau` 已知时 Qini 的真值可直接算，不需要 IPW：

```
Q_true(f_k) = (1/n) * Σ_{i in top-k} tau_i
```

n_test = 2000 的连续 RCT 上：

| 层 | 真值 | IPW 估计 | 估计 − 真值 |
|---|---|---|---|
| 随机排序 | 0.0076 | 0.1140 | 0.1065 |
| 模型排序 | 0.2618 | 0.3121 | 0.0503 |
| oracle 排序 | 0.2887 | 0.3477 | 0.0591 |

- **排序损失** = oracle 真值 − 模型真值 = 0.0269（占天花板 9.3%）
- **估计噪声** = oracle 估计 − oracle 真值 = 0.0591（占天花板 20.5%）
- **排序效率** = 模型真值 / oracle 真值 = 0.907

### 10.3 最有用的一个数：噪声标尺

随机排序的真值 Qini 系数**恒等于 0**（`Q_true(f) = f·ATE` 是直线，面积正好
等于随机线下的面积）。所以随机排序的 IPW 估计值偏离 0 多少，就是单次估计的
噪声量级——本数据上是 **0.1065**，而 oracle 与模型的真值差距只有 **0.0269**。

> **单次 IPW 估计分辨不出这两个排序的优劣。** 模型已拿到天花板的 90.7%，
> 但这点差距被埋进噪声里了。比较两个模型必须重复抽样取均值。

### 10.4 c-for-benefit 没有真值，只有上界

Qini / TOC 是 `tau` 的函数；c-for-benefit 的「观测获益」里混着不可消除的个体
结局噪声（配对两人基线差 + 结局噪声差），排序完美也到不了 1。

观测获益 = `tau + eta`，比较两对时信号 `D = tau_i - tau_j` 与噪声独立正态，
于是 `(D, D+eta)` 是二元正态，相关 `rho = sd(tau)/sd(观测获益)`，
同号概率 = `1/2 + arcsin(rho)/pi`：

```
rho = 0.973 / 1.905 = 0.511
理论天花板 = 0.5 + asin(0.511)/pi = 0.6706
oracle 实测 0.6638  ← 差 0.007，吻合
模型实测   0.6457  ← 拿到 (0.646-0.5)/(0.671-0.5) ≈ 85%
随机       0.5062
```

所以 c-for-benefit 报 0.65 **不是「不够接近 1」——这个数据的信息上限就是 0.671**。
抬高天花板只能提高信噪比（更精确的结局测量、异质性更大的亚群）。

### 10.5 观察性数据：偏差与噪声是两回事

| 层 | Qini 系数 |
|---|---|
| 模型真值 | 0.2523 |
| oracle 真值 | 0.2850 |
| 传 propensity | 0.2666（残差 0.014 = 噪声） |
| 不传 propensity | 1.0535（偏差 0.801 = 混杂） |
| 噪声标尺 | 0.0383 |

传了 `propensity` 的残差落在噪声量级内；不传则偏出 21 倍噪声——**这是系统错，
不是抖动**。所以「不传 propensity」的读数没有讨论价值，它根本不是对真值的估计。

### 10.6 三类结局：同一套指标，标尺不同（脚本 12）

`qini_curve()` / `qini_coefficient()` / `c_for_benefit()` / `toc_curve()` /
`dr_pseudo_outcome()` 对**连续、二分类、生存**三类结局都能用，调用方式完全一样，
差别只在内部怎么把结局压成可比较的评分：

| 结局 | 压成的 `y` | 权重 `w` | 效应标尺 |
|---|---|---|---|
| 连续 | `Y` | 1 | 均值差 |
| 二分类 | `0/1` | 1 | 风险差 |
| 生存（默认 `survdiff`） | `I(T > t0)` | `I(可观测) / Ĝ(min(T,t0))` | S(t0) 差 |
| 生存（`effect = "rmst"`） | `δ·min(T,t0) / Ĝ(T)` | 1 | t0 内 RMST 差 |

生存那条最关键：必须先固定时点 `t0`（不传时默认取事件时间中位数），
把结局压成里程碑指标 `I(T > t0)`，效应标尺才是 S(t0) 差——
与 `metalearner()` 的生存 CATE 定义一致。**标尺不一致，排序比较就没有意义。**
删失用完整病例 IPCW 校正。

```r
# t0 不传时默认取事件时间的中位数
qini_coefficient(cate, d$A, d$Y, t0 = 2)                  # S(t0) 差
qini_coefficient(cate, d$A, d$Y, t0 = 2, effect = "rmst") # RMST 差
c_for_benefit(cate, d$A, d$Y, t0 = 2)
dr_pseudo_outcome(d$X, d$A, d$Y, t0 = 2)                  # 生存也能出 DR 伪结局
```

**实测对账**（三类结局各重复 8 次，模型只在训练集 2/3 上拟合，指标在留出集 1/3 上算）：

| 结局 | ATE真值 | Qini oracle | Qini model | Qini random | c4b oracle | c4b model | c4b random |
|---|---|---|---|---|---|---|---|
| 连续 | 1.0433 | 0.3373 ± 0.1348 | 0.3253 ± 0.1613 | −0.0239 ± 0.1398 | 0.6630 ± 0.0199 | 0.6440 ± 0.0228 | 0.4995 ± 0.0282 |
| 二分类 | 0.1312 | 0.0361 ± 0.0120 | 0.0248 ± 0.0096 | −0.0016 ± 0.0172 | 0.6118 ± 0.0276 | 0.5727 ± 0.0213 | 0.5029 ± 0.0287 |
| 生存 | 0.1514 | 0.0386 ± 0.0122 | 0.0385 ± 0.0116 | 0.0010 ± 0.0118 | 0.5777 ± 0.0256 | 0.5746 ± 0.0242 | 0.4944 ± 0.0247 |

三层排序的次序在三类结局上都对：**oracle ≥ model > random**，
随机排序的 Qini ≈ 0、c-for-benefit ≈ 0.5。生存那行 model 与 oracle 几乎持平，
是因为 T-learner + Cox 在 S(t0) 尺度上已经接近天花板。

**生存的删失校正不是可选项**（n = 20000，真值 0.1514）：

| 算法 | Q(1) | 偏差 |
|---|---|---|
| 完整病例 IPCW（默认） | 0.1424 | −0.0090 |
| 不做删失校正（`w = 1`） | 0.1127 | −0.0387 |

不做 IPCW 会把 Q(1) 从 0.142 压到 0.113，低估约四分之一——
被删失的人被当成「没获益」计入了分母。另外 `rmst` 尺度在删失很重时
还会系统性低估（实测 −0.067），因为权重被截断在 100 以内；
删失重的样本优先用默认的 `survdiff`。

**泄漏对照：拟合顺序决定指标能不能信**（二分类，n = 2400）

| 拟合方式 | c-for-benefit | 与真 tau 的相关 |
|---|---|---|
| 全集拟合后切留出集（泄漏） | 0.8910 | 0.542 |
| 只在训练集拟合（正确） | 0.5583 | 0.655 |
| 真 tau（oracle） | 0.6045 | 1.000 |

泄漏版的 CATE 与真 `tau` 相关反而**更低**（0.542 < 0.655），
c-for-benefit 却高得多——这正是「记住了 Y」的特征：指标变好而排序变差。
二分类下尤其致命，因为观测获益就是 `Y_treated − Y_control`。
**先切分、后拟合**，是硬规矩。

### 10.7 两个实践提醒

- **TOC 曲线最左端不可信**：`TOC(f_k) = (1/k)·Σ s_i`，`k` 很小时单个样本的
  `Y_i/e_i` 主导均值，而 `e_i` 可能只有 0.01（本数据实测冲到 20+）。只看
  `f ≥ 0.1`；极端分位要推断请用 `n_bins` 分箱或换 DR/AIPW 评分。
- **判别力 ≠ 无偏性**：CATE 整体放大 10 倍，Qini / c-for-benefit 完全不变，
  但 ATE 会错 10 倍。两者要分开报。

## 11. 用 mlr3 体系换基学习器（脚本 13）

选 mlr3 体系而不是自己写一套训练循环，最大的好处就在这里：**五种 metalearner 只是「配方」，真正干活的是基学习器；换算法只是换 `learner_base` 一行**，其余代码、接口、工作流原样不动。

同一套 T-learner，把随机森林换成 XGBoost / GLMnet / CART / 线性回归，只改一处：

```r
fit <- metalearner("T", X, A, Y, learner_base = lrn("regr.ranger"))   # 随机森林
fit <- metalearner("T", X, A, Y, learner_base = lrn("regr.xgboost"))  # XGBoost
fit <- metalearner("T", X, A, Y, learner_base = lrn("regr.glmnet"))   # Lasso
fit <- metalearner("T", X, A, Y, learner_base = lrn("regr.lm"))       # 线性回归
```

脚本 13 在连续 RCT 模拟数据（n = 4000，真值 ATE = 1.048）上把五种基学习器各跑一遍，
对比 ATE 与「CATE 与真 τ 的相关」（排序能力）：

| 基学习器 | ATE | ATE 偏差 | CATE 相关 |
|---|---|---|---|
| ranger（随机森林） | 0.9496 | -0.098 | 0.843 |
| xgboost | 0.9601 | -0.088 | 0.656 |
| glmnet（Lasso） | 0.9545 | -0.093 | 0.986 |
| rpart（CART） | 0.9572 | -0.091 | 0.907 |
| lm（线性回归） | 0.9546 | -0.093 | 0.987 |

两个要点：① ATE 估计对基学习器选择相当稳健（偏差都在 ±0.1 内），因为 T-learner 的无偏性不依赖基学习器；② 但**排序能力（CATE 相关）随算法差异很大**——线性模型在这个有交互的 DGP 上反而排得最准，随机森林最差。这正说明换算法不是装饰，它直接决定你能否找到「谁更获益」。

进阶：因为 `lrn("regr.metalearner")` 是正规 R6 Learner，换好基学习器后，`benchmark()` / `tune()` / `resample()` 完全照常。脚本 13 用 `benchmark_grid()` 把「T + ranger」和「T + xgboost」放进同一次 5 折 CV 比 MSE，不用为每种算法单独写循环。这就是「用 mlr3 体系」而不是「又造一套训练管道」的甜头：从教学到调参、从单模型到交叉验证对比，整条链路免费继承。
